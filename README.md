**Purple Chat** — это приватный децентрализованный мессенджер, разработанный для безопасного общения без компромиссов. Проект сочетает в себе скорость прямых P2P-соединений и надежность облачных технологий, обеспечивая при этом сквозное шифрование (E2EE) уровня Enterprise.

---

## ✨ Ключевые возможности

- **🔐 Пост-квантовая криптография:** Гибридная схема на базе ML-KEM-768 (FIPS 203) и XChaCha20-Poly1305.
- **⚡ Гибридная доставка данных:** Умный роутер сам решает, как отправить сообщение. Если собеседник онлайн — через WebRTC (напрямую). Если офлайн — в зашифрованное облако.
- **🎙️ Медиа и голосовые:** Отправка файлов, фото и запись голосовых сообщений прямо в браузере.
- **📞 P2P Аудиозвонки:** Прямая передача звука между устройствами без серверов-посредников.
- **🛡️ Zero-Knowledge Архитектура:** Сервер видит только зашифрованный мусор.
- **🎨 15+ тем оформления:** От строгого Glassmorphism до неоновых цветов.

---

## 🏗 Архитектура и Безопасность

В основе проекта лежит принцип **Zero-Knowledge**. Даже если сервер будет взломан, злоумышленники не получат доступ к переписке.

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| **Обмен ключами** | ML-KEM-768 | Пост-квантовая защита от перехвата |
| **Шифрование данных** | XChaCha20-Poly1305 | Симметричное шифрование сообщений и файлов |
| **Локальная БД** | IndexedDB + ChaCha20 | Защита кэша на устройстве (at-rest encryption) |
| **Хэширование паролей** | Argon2id | Защита от брутфорса |
| **Сеть** | WebRTC / Trystero | Прямая передача P2P (без сервера) |

### Как это работает?
1. **Приватные ключи** генерируются на устройстве пользователя и **никогда** не покидают его. 
2. **Медиа и текст** шифруются перед отправкой (сервер получает только шифротекст).
3. **Восстановление доступа** возможно только через уникальный *Recovery Key* (16 символов).
